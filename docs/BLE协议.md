# BLE 通信协议（SmartGarden）

## 服务与特征值

| 角色 | UUID | 属性 |
|---|---|---|
| 服务 | `0xFFF0` | Primary Service |
| 环境数据 | `0xFFF1` | Notify（设备 -> App） |
| 控制指令 | `0xFFF2` | Write（App -> 设备） |
| 心跳 | `0xFFF3` | Notify / Write |

## 帧格式

```
| SOF | TYPE | LEN | PAYLOAD | CRC8 |
  1B    1B    1B    0-20B     1B
```

- `SOF` = `0xAA`
- `CRC8` 覆盖 `TYPE + LEN + PAYLOAD`

## 环境数据帧（0x01，Notify）

| 字段 | 长度 | 说明 |
|---|---|---|
| 温度 | 2B | 0.1℃ 为单位，大端 |
| 湿度 | 2B | 0.1% 为单位 |
| 土壤湿度 | 2B | 0-100 |
| 光照 | 2B | lux |
| 水泵占空比 | 2B | 千分比 |
| 补光占空比 | 2B | 千分比 |

## 控制指令帧（0x02，Write）

| 字段 | 长度 | 说明 |
|---|---|---|
| 模式 | 1B | 0=自动 1=手动 |
| 水泵占空比 | 2B | 手动模式下生效 |
| 补光占空比 | 2B | 手动模式下生效 |

控制指令由 BLE 任务写入 `cmd_queue`，控制任务优先执行手动指令，超时无指令则回到自动闭环。

## 心跳保活（0x03）

设备每 1s 发送心跳帧，App 应答。连续 3 次无应答判定连接异常，设备主动断开并重新广播，
避免"连接已断但状态未更新"导致的控制失效。
